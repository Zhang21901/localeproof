How to use the free demo

  1. Try the sample, or choose a bilingual XLSX, UTF-8 CSV or TSV.
  2. Put headers in row 1. Choose your source, translation and optional ID columns. Select a worksheet for Excel files.
  3. Choose the number conventions used in each column: English, German or French.
  4. Run the check. Review findings, mark intentional differences ignored and add notes.
  5. Export CSV before closing the tab. Review notes and imported files are not saved.

Limits and interpretation

One file, 100 non-empty segments per check, 10 MB input. The workbook guard checks actual expanded content before parsing. Up to 20 worksheets, 100 columns and 20,000 data rows can be parsed; the selected data must fit the 100-segment demo.

This is deterministic comparison, not translation or linguistic quality scoring. Tags, placeholders, numbers, links, empty translations, repeated source consistency and whitespace are checked. ICU branches, grammar, meaning and tag nesting need dedicated review. Non-positional printf arguments should be reviewed manually. Findings may be intentional; review them in context.

Current release has been exercised in Chromium. Native Firefox and Safari checks remain pending. Desktop is recommended for spreadsheet review.
