A few good questions.

Do my files get uploaded?

No. Parsing, checking and report generation happen in your browser. This public demo has no account or billing connection. This site has no document-upload API and no analytics trackers.

Will this translate or rewrite my text?

No. LocaleProof compares source and target text using defined checks. You review the findings and make changes in your original file.

Does it work on a Mac?

It is built for current Chrome, Firefox, Safari and Edge browsers. There is no Windows application or virtual machine to install. The delivered build has been tested in Chromium; a native Safari and Firefox release check is listed in the launch guide.

Which files and languages can I check?

Bilingual XLSX, UTF-8 CSV or TSV with one source and one translation column. Choose a worksheet and column mapping per file. Text may be in any language; number normalization currently offers English, German and French conventions. See the guide for glossary boundaries and unsupported ICU syntax.
